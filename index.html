How to Use

1. Character Builder: Create your character sheet or load an existing one. Export it as JSON and save to the shared folder (ask the DM for the link).

2. Adventure Journal: Record your discoveries, NPCs you meet, quests, and memories as you adventure.

3. Compendium: Reference rules, creature stats, and world lore during play.

💾 Saving: All tools auto-save to your browser. Export your data regularly as backup.

Setup Instructions

Before your first session:

Set up a shared Google Drive folder for your campaign

Share the folder link with all players

Players create characters in the Character Builder

Players export their sheets as JSON and upload to the Drive

Import player sheets into Encounter Control when you need them

Need help? All tools have built-in export/import — no manual setup required beyond sharing the Drive folder.
