# Decide Your Own Path

A free set of browser tools for **Decide Your Own Path**, a classless homebrew
tabletop system compatible with fifth edition.

Everything is a single static HTML file with no server, no accounts and no build
step. Open the live site, or fork the repo and run your own copy:

**https://aurickbr.github.io/Decide_Your_Own_Path/**

| Tool | What it does |
|---|---|
| `index.html` | Campaign portal — the entry point |
| `character-builder-2.html` | Character creation and the playable sheet |
| `journal.html` | Adventure journal |
| `compendium-and-bestiary.html` | Rules, creatures and lore reference |
| `encounter-control.html` | DM combat tracker |
| `dm-loom.html` | DM worldbuilding forge and codex |
